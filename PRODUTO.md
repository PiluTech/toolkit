## O que está sendo feito

O toolkit está no começo: a arquitetura está escrita, e o código sai por fases. Ainda não há versão publicada.

- Um comando só para preparar uma máquina Windows, Linux ou macOS.
- Um catálogo de apps em YAML: para cada sistema, o toolkit usa o gerenciador de pacotes que a máquina tiver.
- Receitas de várias etapas que continuam depois de reiniciar, com cada etapa conferindo antes se já está feita.
- Todo download direto com o SHA-256 conferido.
- Uma interface no terminal e os mesmos comandos sem ela, para automação.
